# E2E-tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Playwright-e2e-tests (WebKit, iPad + iPhone) voor vier flows, tegen de productiebuild en een lokale Supabase, lokaal en in CI.

**Architecture:** Nieuw workspace-pakket `apps/e2e`. De config leest URL en sleutels uit `supabase status -o env` en weigert alles behalve localhost. Playwright bouwt de web-app met die sleutels, controleert de bundel en start `vite preview`. Fixtures maken per test verse gebruikers via de Supabase admin-API.

**Tech Stack:** `@playwright/test` (WebKit), `@supabase/supabase-js` (service role, alleen testkant), vitest (unittests hulpcode), Supabase CLI 2.72.7, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-12-e2e-testing-design.md`

## Global Constraints

- Alleen WebKit; projecten `webkit-ipad` (`devices['iPad Pro 11']`) en `webkit-iphone` (`devices['iPhone 14']`).
- Nooit tegen de clouddatabase: host van de Supabase-URL moet `localhost` of `127.0.0.1` zijn, anders stopt de run.
- Geen sleutels in de repo; uitlezen via `supabase status -o env`.
- `apps/web` importeert nooit `@supabase/supabase-js`; `apps/e2e` mag dat (testcode), vermeld in `docs/ARCHITECTURE.md`.
- App onder test: `vite preview --port 4173 --strictPort`, `reuseExistingServer: false`, `serviceWorkers: 'block'`.
- Retries: 0 lokaal, 1 in CI. `trace: 'retain-on-failure'`.
- Selectors op rol, label, placeholder en zichtbare Nederlandse tekst; geen CSS-klassen.
- Commitberichten in het Nederlands, eindigen met `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`; geen "Generated with Claude Code"-regel.
- Branch `feature/e2e` in `.worktree/e2e`, PR naar `develop`.

## Review Focus

- `apps/web/.env` bevat lokaal de cloud-URL → de e2e-build moet toch de lokale URL gebruiken. Vastgelegd door `check-build.mjs` (Task 1).
- Lokale Supabase draait niet → duidelijke melding "Start eerst de lokale Supabase: supabase start", geen stacktrace van `execSync`. Unittest in Task 1.

- [ ] **Step 3: `supabase-env.ts`**

```ts
import { execSync } from "node:child_process";
import { fileURLToPath } from "node:url";

/** URL en sleutels van de lokale Supabase, uitgelezen met `supabase status -o env` */
export interface SupabaseEnv { url: string; anonKey: string; serviceRoleKey: string }

const REPO = fileURLToPath(new URL("../..", import.meta.url));

export function parseStatusEnv(text: string): Record<string, string> {
  const env: Record<string, string> = {};
  for (const m of text.matchAll(/^([A-Z0-9_]+)="(.*)"$/gm)) env[m[1]!] = m[2]!;
  return env;
}

/** e2e maakt en wijzigt gebruikers: nooit tegen de gedeelde clouddatabase */
export function assertLocal(url: string): void {
  const host = new URL(url).hostname;
  if (host !== "localhost" && host !== "127.0.0.1") throw new Error(`E2E draait alleen tegen een lokale Supabase, niet tegen ${host}`);
}

let cached: SupabaseEnv | undefined;
export function loadSupabaseEnv(): SupabaseEnv {
  if (cached) return cached;
  let out: string;
  try { out = execSync("supabase status -o env", { cwd: REPO, encoding: "utf8", stdio: ["ignore", "pipe", "ignore"] }); }
  catch { throw new Error("Start eerst de lokale Supabase: supabase start"); }
  const env = parseStatusEnv(out);
  if (!env.API_URL || !env.ANON_KEY || !env.SERVICE_ROLE_KEY) throw new Error("Start eerst de lokale Supabase: supabase start");
  assertLocal(env.API_URL);
  return (cached = { url: env.API_URL, anonKey: env.ANON_KEY, serviceRoleKey: env.SERVICE_ROLE_KEY });
}
```

import { randomUUID } from "node:crypto";
import { test as base, expect, type Page } from "@playwright/test";
import { createClient, type SupabaseClient } from "@supabase/supabase-js";
import { loadSupabaseEnv } from "./supabase-env";

export { expect };
export type Rol = "leerling" | "ouder" | "leraar";
export interface Gebruiker { id: string; email: string; password: string; naam: string; rol: Rol }
export const WACHTWOORD = "e2e-wachtwoord";

/** uniek per test, zodat parallelle tests elkaar niet raken */
export const nieuwEmail = (rol: string) => `e2e-${rol}-${randomUUID().slice(0, 8)}@example.com`;

export const test = base.extend<{
  admin: SupabaseClient;
  maakGebruiker(rol: Rol, naam?: string): Promise<Gebruiker>;
  maakKind(ouder: Gebruiker, naam: string): Promise<string>;
}>({
  admin: async ({}, use) => {
    const { url, serviceRoleKey } = loadSupabaseEnv();
    await use(createClient(url, serviceRoleKey, { auth: { persistSession: false, autoRefreshToken: false } }));
  },
  maakGebruiker: async ({ admin }, use) => {
    await use(async (rol, naam = rol === "ouder" ? "Ouder" : rol === "leraar" ? "Leraar" : "Leerling") => {
      const email = nieuwEmail(rol);
      // leerling en ouder: zoals bij zelf registreren (trigger handle_new_user); leraar alleen via de service role
      const meta = rol === "leraar" ? { display_name: naam } : { role: rol, display_name: naam };
      const { data, error } = await admin.auth.admin.createUser({ email, password: WACHTWOORD, email_confirm: true, user_metadata: meta });
      if (error || !data.user) throw error ?? new Error("gebruiker niet aangemaakt");
      if (rol === "leraar") {
        const { error: e } = await admin.from("profiles").update({ role: "leraar" }).eq("id", data.user.id);
        if (e) throw e;
      }
      return { id: data.user.id, email, password: WACHTWOORD, naam, rol };
    });
  },
  maakKind: async ({ admin }, use) => {
    await use(async (ouder, naam) => {
      const { data, error } = await admin.from("students").insert({ owner_id: ouder.id, name: naam, instrument_id: "altsax" }).select("id").single();
      if (error) throw error;
      return data.id as string;
    });
  },
});
